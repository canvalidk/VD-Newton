# Prediction Sets And Honest Newtonian Rejection

## Claim

Newtonian mechanics does not honestly predict only a single point outcome such
as:

```text
particle p will be at position x at time t
```

In actual scientific use, accepting Newtonian mechanics means accepting a
broader prediction set: a structured set of Newton-licensed possibilities that
must be exhausted before Newton itself is rejected.

This matters because many historical "failed predictions" of Newton were not
failures of the full Newtonian prediction set. They were failures of a narrow
hypothesis produced under some modelling setup. Newton persisted when another
branch of the honest prediction set remained live and could be made concrete.

The discovery of Neptune is the clean example: Uranus did not match the simple
point prediction, but Newtonian mechanics licensed the branch that an
unaccounted external body was influencing the system. That branch became a
search demand and was vindicated.

## Rough Newtonian Prediction Set

For a Newtonian prediction about a system of particles, the honest prediction
set includes at least:

- the particle is at the predicted point at the predicted time;
- someone made a mistake producing the hypothesis;
- the inputs or measurements used to produce the hypothesis were wrong;
- the chosen frame was not an appropriate inertial frame;
- there are external influences on particles in the system;
- there are unaccounted acting objects on particles in the system;
- the system is influencing an external particle;
- the approximation regime failed;
- a required Newtonian referent is undefined or outside the theory's domain;
- Newtonian mechanics is failing in this domain.

The point is not that all branches are equally good. The point is that an
honest Bayesian accounting of Newtonian mechanics includes these branches with
different costs, not just the point prediction branch.

## Honesty Requirement

Prediction sets are dangerous if they become after-the-fact excuses.

The VD makes them accountable by requiring each Newton-preserving branch to be
traceable to the theory's own structure:

- calculation mistakes are tied to trace production and expansion errors;
- bad inputs are tied to witness sheets, walls, and model inputs;
- bad frames are tied to the inertial-frame commitment and the
  `acceleration` / `inertial-acceleration` bridge;
- external influences are tied to closure and unpaired force accounting;
- unaccounted acting objects are tied to mechanical-composition and dispatch;
- approximation failures are tied to modelling assumptions and regimes;
- undefined referents are tied to halts such as missing `inertial-mass`;
- theory failure remains the branch reached when no licensed rescue branch
  remains credible.

So "someone made a mistake" is not dishonest by itself. It becomes dishonest
only if it is left as a vague unpriced escape hatch. In a VD setting, it should
become a concrete trace audit claim.

## Academic Value

Without the VD, prediction sets can look like a wild west. If Newton is
identified only with its equations, then every failed point prediction seems
to force an awkward choice:

```text
reject Newton immediately
or protect Newton with informal auxiliary excuses
```

Actual science does neither. It uses a disciplined diagnostic ecology:
recheck the calculation, remeasure, inspect the frame, search for missing
sources, open the system boundary, revise the model, or finally reject the
theory in that domain.

The VD's value is that it can make this ecology explicit. It turns
theory-protective reasoning into a ledger rather than a private expert habit.

## Post-Design-3 Goal

After Newton Design 3 is stable enough to produce accountable traces, test
whether prediction sets can be generated from the VD entries themselves.

The goal is not merely to list excuses. The goal is to produce the honest set
of theory-licensed branches that would have to be false, exhausted, or assigned
low enough probability before Newtonian mechanics is rejected.

Success would look like:

```text
given a Newtonian trace and a failed observation,
the VD exposes the licensed Newton-preserving branches,
the cost or demand of each branch is visible,
and theory failure appears as the remaining branch when those routes close.
```

This would make Newtonian falsifiability less naive, not weaker.
