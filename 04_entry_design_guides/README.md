# Entry Design Guides

This folder holds working guides for drafting, checking, and revising VD
entries.

## Entry Packets

An **entry packet** is the copy/paste working card in
`VD_NEW_ENTRY_TEMPLATE.md`.

Use an entry packet when drafting or revising a single entry. It records the
entry id, headword, structural role, source material, trace-critical headword
mentions, residual logic/effects, witness slots, draft wording, and open
questions in a compact form.

When a conversation says "entry packet," it means this fillable block, not a
finished VD entry.

## Useful Starting Points

- `VD_NEW_ENTRY_TEMPLATE.md` - copy/paste entry packet and optional audit
  add-on.
- `entry_writing_guide_auditable_compositions.md` - residual provenance
  ledger discipline; promote novel figures to entries or compose only from
  installed reactions.
- `vd_entry_writing_best_practices_handle_residual.md` - residual/handle

- `vd_six_entry_structure.md` - chimney, triplet, and wall structure.
- `vd_acting_object_entry_authoring_guide_plan_v1.md` - acting-object entry
