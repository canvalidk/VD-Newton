# VD Newton Design 3 Catch-Up Pack

This folder is a compact orientation layer over the mixed Design 3 notes in
`VD docs`. It does not replace the original documents. It records which notes
are currently steering the design, which are historical, and what has to be
remembered when drafting Design 3 entries or traces.

## Fast Reading Order

Read these first, in this order:

1. `CURRENT_STATE.md`
   - The current Design 3 synthesis.
   - Use this as the working mental model before reading any older note.

2. `SOURCE_STATUS.md`
   - Which source documents are current, partially superseded, or historical.
   - Includes exact source paths.

3. `DESIGN_3_GOALS.md`
   - The distilled goals and entry-work still standing.
   - Useful before writing or reviewing entries.

Then read the original sources only as needed:

1. [VD-docs: Newton-analysis/vd_design_3_newton_i_correction.md](https://github.com/canvalidk/VD-docs/blob/main/Newton-analysis/vd_design_3_newton_i_correction.md)
2. `vd_acting_object_architecture_consolidation.md`
3. `vd_design_3_todo.md`
4. `vd_design_3_oop_discussion.md`
5. `unfolding_forces.md`
6. `vd_design_3_identity_discussion.md`
