# Newtonian Mechanics Lesson Drafts

Status: working lesson-draft archive, started 2026-06-04.

This folder stores Newtonian Mechanics lesson drafts separately from the entry
ledger and design notes. The intent is to keep runnable classroom lesson
documents visible while allowing placement notes and later lesson drafts to
develop alongside them.

## Folder Pattern

```text
nml1/
  nm_l1_lesson_draft.md
  NM_L1_E7_integrated_complete_draft.md
  NM_L1_E7_E8_decision_note.md
  E7_INERTIAL_ACCELERATION_PLACEMENT_NOTE.md
```

Future lesson drafts can follow the same shape:

```text
nml2/
  nm_l2_lesson_draft.md
  placement / boundary notes as needed
```

## Preservation Rule

Copied lesson drafts should be treated as preserved working drafts unless a
later task explicitly asks to edit them. Placement notes, curriculum notes, and
entry-selection notes should live beside the draft rather than being folded
into it too early.
