# Newton Analysis

This folder is the access shelf for Newton analysis insights: conceptual
discoveries that surfaced while encoding Newtonian mechanics in the VD, but
which are not themselves the active Newton entry set.

Use this folder when you want the "what did the formalization reveal?" layer:
the hidden commitments, boundary cases, cross-theory analogies, and corrections
that are too important to leave scattered across old conversation notes.

## Current Anchor

- `prediction_sets.md`
  - Prediction sets are the honest set of Newton-licensed possibilities that
    must be exhausted before Newtonian mechanics is rejected.
  - The VD can make theory-protective reasoning auditable instead of leaving it
    as informal auxiliary-hypothesis drift.
  - This is a post-Design-3 goal: test whether prediction sets can be generated
    from the entries and traces themselves.

- `randomness_declarative_boundary.md`
  - Randomness is not an ordinary object-backed attribute in a declarative
    structure.
  - The trace can mark a random boundary, bind the sampled or observed value,
    and use that value later.
  - In QM-style cases, the VD should not automatically infer a missing ordinary
    object witness for the exact outcome unless the theory explicitly adds
    hidden structure.

This note is mirrored from `05_design_3_catchup/RANDOMNESS_DECLARATIVE_BOUNDARY.md`
because it is both a Design 3 concern and a Newton analysis insight.

## Reading Clusters

Frame and Newton I:

- `newton_first_law_article.md`
  - Newton I as the gatekeeper for inertial-frame force accounting.
  - Explains why fictitious forces break the acting-object and closure
    machinery.

- `vd_design_3_newton_i_correction.md`
  - Corrects earlier Newton I routing claims.
  - Treats Newton I as the bridge between raw `acceleration` and
    `inertial-acceleration`, not as a branch that all free particles route
    through.

Force objects, composition, and closure:

- `vd_composition_discovery_note.md`
  - Mechanical-composition as the particle-owned set of acting objects.
  - Connects Newtonian acting-object structure to the computer-science
    "has-a" meaning of composition.

- `abstract_interaction_candidate.md`
  - Interaction candidate as a theory-independent structural object.
  - Keeps the abstract idea of interaction separate from conservation
    assumptions.

Ontology boundaries and cross-theory pressure:

- `prediction_sets.md`
  - Newtonian mechanics as producing structured null-hypothesis sets, not only
    point predictions.
  - Explains why failed point predictions can strengthen Newton when a licensed
    branch, such as an unaccounted external body, becomes concrete.

- `nothing_vs_zero_somethings.md`
  - Historical but still useful.
  - Shows how zero-force handling, massless particles, and force-pipeline
    domain limits expose structural boundaries.
  - Read alongside `vd_design_3_newton_i_correction.md`, which supersedes its
    Newton I routing claim.

- `newton_vs_gibbs.md`
  - Newtonian mechanics as committing to particle distinguishability.
  - Gibbs correction as the classical sign that this commitment is being
    subtracted elsewhere.

- `randomness_declarative_boundary.md`
  - Random outcomes as boundary inputs rather than ordinary witness-sheet
    attributes.
  - Useful for thinking about QM without smuggling in hidden object-backed
    determiners.
